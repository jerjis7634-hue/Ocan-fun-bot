# Ocean Fun — ربات بازی گروهی تلگرام

این پروژه یک ربات تلگرامی فارسی با ساختار شبیه نمونه‌ای است که فرستادی:
- پروفایل و امتیاز
- بازی‌های گروهی
- جدول رتبه‌بندی
- جایزه روزانه
- فروشگاه مجازی
- دکمه‌های شیشه‌ای/Inline
- دیتابیس SQLite
- قابل افزودن به گروه

## راه‌اندازی
1. در @BotFather یک Bot بساز و توکنش را بگیر.
2. فایل `.env.example` را به `.env` تغییر نام بده.
3. مقدار `BOT_TOKEN` را وارد کن.
4. نصب:
   `pip install -r requirements.txt`
5. اجرا:
   `python bot.py`

## افزودن به گروه
بات را به گروه اضافه کن. برای بازی‌های گروهی، اعضا روی «🎮 بازی گروهی» می‌زنند و بازی در همان گروه شروع می‌شود.

این نسخه عمداً پول واقعی/شرط‌بندی ندارد و از سکه مجازی استفاده می‌کند.
